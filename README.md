> **视野有限，感知无界。** 把视野之外的战局，交给耳朵和手。
>
> **本仓库是第三方项目推介页，不是官方仓库**：原项目由 ld0574 团队独立开发（「罕见·无界黑客松」参赛项目），代码、文档与官方页面均在上游，本页只做介绍与推荐。

## 它是什么（项目描述）

听野（SenseField）是一款面向低视力玩家的无障碍游戏辅助：通过**声音、语音、触觉与视觉高亮**，把屏幕上玩家视野之外的游戏信息「翻译」成另一种感官通道——同时坚持三条底线：**不模拟触控、不代替操作、不注入游戏**。

- 核心识别与预警在**手机本地**完成，**离线可用**（不依赖网络）
- 画面获取走**系统屏幕录制**，不读取游戏内存、不注入、不模拟触控
- Apache-2.0 开源

## 核心功能

| 功能 | 说明 | 状态 |
|---|---|---|
| 🎧 耳边的小地图（王者荣耀辅助） | 手机本地识别小地图中可见的敌方信息，以方向短音与简短语音提醒附近动向 | 官网演示 |
| 🎯 棋盘上的线索（开心消消乐辅助） | 播报行列并高亮建议交换的棋子 | 官网口径：已测通 120 关 |
| 🤖 随你开启的助手（实验功能） | 语音本地识别；画面问答走线上服务 | 默认关闭，需单独授权 |

## 产品使用与当前进度（云端 + 本地模型分工）

*口径：听野官网 + 上游仓库 README/validation/STATUS.md，2026-11-21 实测提取。*

| 层 | 跑在哪 | 说明 |
|---|---|---|
| 核心识别与预警 | **手机本地**，离线可用 | C++（ncnn）小地图识别；核心预警不上传画面、不依赖网络 |
| 助手 · 语音 | **手机本地** | 首次下载约 153 MiB 识别资源，校验后离线运行；不开启助手不下载 |
| 助手 · 画面问答 | **线上服务** | 默认关闭、需单独授权；仅发送问题文字 + 当前截图 + 最多两张近期缩图（HTTPS 到助手网关与视觉模型，模型 API 密钥留服务端） |

**当前进度**（上游 STATUS.md 与官网口径）：

- 最新发行版 **v0.4.8**（Android 10+，arm64）；「罕见·无界黑客松」**十强赛手团队 · 最佳人气奖**
- 开心消消乐：**已测通 120 关**（STATUS.md 明确口径；不同机型/关卡/游戏版本需实际确认）
- 官网如实声明仍在持续验证：王者提醒的**独立准确率**、**跨设备声音**、**长时间运行**、**温升**与目标玩家体验；「现有结果不代表所有关卡与设备上的效果保证」
- 验证纪律：测试结果绑定对应源码/安装包/输入，避免历史结果沿用到其它制品（validation/STATUS.md）

**游戏适配与后台画面识别**：

- 已适配：**王者荣耀**（小地图敌方信息本地识别 → 筛选/去重 → 方向短音+语音方位提醒）、**开心消消乐**（棋盘确认 → 亮框/箭头/方位语音提示交换位，按关卡目标排序）；更多游戏适配经用户反馈表收集扩展
- 游戏模型与识别模板**按需下载**：首次使用对应游戏时下载、校验后本机离线复用，不打入 APK
- 画面获取走 Android **MediaProjection**（每次玩家授权）；只解释界面已呈现的信息——**不读进程/内存、不注入、不模拟触控**；后台识别即「屏幕采集→本地识别→筛选排序去重→提醒/高亮→玩家自主操作」链路
- 视觉高亮需悬浮窗权限；官网未公布具体帧率/内存/温升数字（诚实边界）

## 目标人群

- **优先面向**：管状视野、周边视野缺损、且仍能完成主要操作的低视力玩家
- **明确边界**：目前**不支持全盲玩家**；不能替代专业无障碍评估
- 适配偏好可调：声音、语速与提醒方式可自定义

## 隐私与合规

- 通过系统屏幕录制获取画面；不读内存、不注入、不模拟触控
- 可选智能助手默认关闭，启用需单独授权；其画面问答会发送截图与近期缩图至线上模型服务
- 与腾讯、天美工作室群及游戏官方**无隶属或认可关系**
